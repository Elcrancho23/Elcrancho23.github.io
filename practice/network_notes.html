Networking Definitions

Protocol

A protocol is a set of rules that devices follow to communicate over a network.

Packet

A packet is a small chunk of data sent across a network.

Header

The header is the part of a packet that contains control information, like source and destination.

Payload

The payload is the actual data being carried in a packet.

Router

A router is a device that forwards packets between networks.

Routing Table

A routing table is a list in a router that tells it where to send packets.

Summary

Networking uses protocols to guide communication. Data travels in packets with headers and payloads. Routers use routing tables to direct these packets to their destinations.
