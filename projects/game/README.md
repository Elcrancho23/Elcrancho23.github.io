
    Jungle temple

 You are a famous explorer that wants explore the ancient jungle and in the heart of it there is a temple that is filled with riches but also has deadly traps. 

You must recover the golden Idol and unlock the tresure room but some rooms have dadly traps.

- Find the Golden Idol
-Find the Key
-Avoid the traps
-Find the Idol and win the game

Mermaid: 

    A[Jungle Path] ->|entrance| B[Entrance]
    A->|booby trap| K(Booby Trap)<- TRAP
    A->|idol chamber| G[Idol Chamber]
    B-> |hallway| C[Hallway]
    B->|snake pit| J(Snake Pit)<- TRAP
     B-> |jungle path| A
    C >|treasure room| D[Treasure Room]
    C->|hidden chamber| E[Hidden Chamber]
    C-> |entrance| B
    E->|hallway| C
    G-> |deep pit| I(Deep Pit)<- TRAP
    G->|jungle path| A

Global Variables 

- gameActive: This indecates if the game is running 
- hasKey: true if the player picks up the KEY 
-hasIdol: true if the player grabs the golden idol


How to win or lose 

Win: Find the idol and key then get to the tresure room
Lose: Enter a trap room
